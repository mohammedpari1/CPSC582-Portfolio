# CPSC 582 — Individual Design Portfolio

A responsive static website for Mohammed Pari's Fall 2026 Human–Computer Interaction II portfolio.

## Contents
- `index.html` — portfolio content and structure
- `style.css` — responsive design and visuals
- `script.js` — navigation, activity filters, reading progress, image viewer
- `assets/` — project and class activity evidence from supplied coursework

## Publish on GitHub Pages
1. Open `https://github.com/mohammedpari1/CPSC582-Portfolio`.
2. Replace existing `index.html`, `style.css`, `script.js`, and the `assets/` images with the contents of this folder. GitHub's Upload files interface can upload the whole `assets` folder by dragging it from Finder.
3. Commit changes to `main`.
4. Under Settings → Pages, use **Deploy from a branch**, **main**, **/(root)**.
5. Open `https://mohammedpari1.github.io/CPSC582-Portfolio/` and verify all sections and images.

## Academic note
This site distinguishes documented individual contributions from team contributions. Read all first-person reflections before submission and revise any statement that does not reflect your experience. Visual hero/interface mockups are illustrative, while images in `assets/` are sourced from the provided reports and class activities.
